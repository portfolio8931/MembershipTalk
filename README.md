# MembershipTalk

## 概要
動画編集をお手伝いさせていただいている配信者様向けに制作した、メンバーシップ雑談配信用の質問表示Webツールです。  
メンバーシップ雑談をマシュマロ（質問投稿アプリ）からGoogleフォームに切り替えた際、配信画面での視認性の問題や、表示時の操作が煩雑になり切り替えに時間がかかってしまうという課題を解決するために開発しました。  
配信者様の作成したCSV（集計、編集後）に合わせて作成しているため、挙動テスト用のCSVをダウンロードしてお試しください。

* **公開URL**: https://portfolio8931.github.io/MembershipTalk/
* **CSVダウンロードリンク(Drive)**: [https://drive.google.com/file/d/11axndFVkSLy8U7FI1sWPxI1yA5JFn-AH/view?usp=drive_link](https://drive.google.com/file/d/11axndFVkSLy8U7FI1sWPxI1yA5JFn-AH/view?usp=drive_link)

## 主な機能
* **CSVファイルの読み込み**
  * 「ファイルを選択」ボタンからCSVを取り込み、「読み込み」を押すことで質問データを一括で表示可能
* **質問の切り替え・表示制御**
  * 左右の矢印ボタンで質問を1問ずつスムーズに切り替え
  * 長い文章の場合は枠内でスクロールして確認可能
  * 右下に全体の件数と現在のページ数を表示
* **切り抜き可否の表示**
  * 質問ごとに「切り抜きOKか」をひと目で確認できる表示欄を設置

## 利用技術
* **HTML5**: 単一ファイルによるシンプルな構造化
* **CSS (SCSS)**: ネストや変数を活用して保守性の高いCSSを設計
* **JavaScript**: スライダー機能および画面切り替え処理
* **PapaParse**: CSVファイルのパース（解析）処理
* **パッケージマネージャー**: Yarn
* **ホスティング**: GitHub Pages

## 実装のこだわり
* **配信画面での利用を想定した画面設計**
  * OBS等の配信ソフトでそのまま画面キャプチャして使用することを前提に、PC閲覧に最適化したレイアウトで制作（一定のブラウザサイズ変更にも対応）
* **配信中のスムーズな操作性**
  * 配信の進行を妨げないよう、シンプルなボタン操作で質問の切替やデータ読み込みができるようUIを設計。
* **配信時間や進行を意識した件数表示**
  * 質問全体の件数と、今何件目かを分かりやすく表示することで、配信者様が時間調整やペース配分をしやすい設計にしました。
* **安全なテキスト表示**
  * CSVから読み込んだテキストを表示する際、HTMLの特殊文字（< や > など）を変換することで、安全に画面表示が行われるよう配慮しました。

## セットアップ手順

### 動作環境
* Node.js
* Yarn

### 手順
1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/portfolio8931/MembershipTalk.git
   cd MembershipTalk
   ```
2. 依存パッケージをインストール、開発用サーバー（ローカル環境）を起動します。
   ```bash
   yarn install
   yarn start
   ```
3. EJSとSCSSをビルドする場合（public/ 配下にファイルを生成）
   ```bash
   yarn build
   ```
